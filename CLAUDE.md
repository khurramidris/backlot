# Backlot: notes for Claude

Backlot is a startup product: prompt → finished film (microdrama, short film, web series, YouTube story).
The founder works with Claude as CTO and the whole engineering team. Ship-oriented: small, tested, pushed.

## Current state
The product is feature-complete for launch: prompt → film, Basic subscription ($20/month through Lemon Squeezy,
monthly plan credit plus top-ups), 50 GB storage quota, billing and account pages, password reset, and
Terms/Privacy drafts. What's left is setting up accounts and inputs only the founder can provide (see "Not done
yet").

## Working rules
- **GitHub `main` is the source of truth.** Commit and push after every meaningful, green step: the founder
  switches between this repo on a laptop and Claude on the web.
- Conventional commits (`feat:`, `fix:`, `chore:`, `docs:`, `refactor:`).
- Never commit secrets. `.env*` files are git-ignored. Document new settings in `engine/env.sample` and
  `docs/DEPLOY.md`.
- Before pushing, run what the change touches (see Tests). CI must stay green.

## Layout
- `engine/`: Node 22 + Hono + Postgres. Entry: `src/index.ts`; routes: `src/server.ts`; pipeline:
  `src/pipeline/*`; money: `src/billing.ts` (credit buckets, plan gate, storage quota) and `src/lemonsqueezy.ts` (payments); RunPod: `src/providers/runpod.ts`, `src/capacity.ts`.
  Migrations in `db/migrations` (applied on boot, append-only).
- `web/`: React + Vite + TanStack Router (file routes in `src/routes`, `routeTree.gen.ts` is generated by the
  build and committed). The API client is `src/lib/engine.ts`. The engine serves the built app.
- `gpu-worker/`: Python RunPod handler. The model plugs in at `backends/h3.py`.
- Architecture and invariants: `docs/ARCHITECTURE.md`. Deployment: `docs/DEPLOY.md`. Brand (colours, type, logo,
  the reference boards): `docs/brand/README.md`. Keep new UI on-brand and use the tokens in `web/src/styles.css`.

## Setup (fresh Linux machine)
```bash
apt-get install -y postgresql ffmpeg fonts-dejavu-core   # plus Node 22 and Python 3.11
npm run setup
```

## Tests
```bash
npm --prefix engine run typecheck && npm --prefix engine test           # fast
npm --prefix web run typecheck && npm --prefix web run lint && npm --prefix web test && npm --prefix web run build
# end to end (each needs its own EMPTY database; mock providers, real FFmpeg):
DATABASE_URL=postgres://postgres@localhost:5432/<db> npm --prefix engine run e2e          # step-by-step pipeline
DATABASE_URL=postgres://postgres@localhost:5432/<db> npm --prefix engine run e2e:vibe     # prompt → paid film
DATABASE_URL=postgres://postgres@localhost:5432/<db> npm --prefix engine run e2e:runpod   # RunPod path + scaling
python gpu-worker/selftest.py
```

## Local run
`MOCK_PROVIDERS=1 ALLOW_DEV_TOKENS=1 DATABASE_URL=… npm run dev:engine` and `npm run dev:web`, then open
localhost:5173. You're signed in as a dev user, and everything is mocked with no keys needed. The engine
refuses to boot with these flags when `NODE_ENV=production`. Credits, the plan gate and the storage quota are
off unless `ENFORCE_CREDITS=1`. To try billing locally, set it with the `LEMONSQUEEZY_*` variables and send
signed webhooks yourself, like `engine/test/vibe.e2e.ts` does.
